# Figures

Run from the repository root, in this order (see the Makefile for the exact arguments).

| Script | Purpose |
|---|---|
| `01_main_figures.py` | Main-text macro figures of the restructured manuscript (five figures). |
| `02_fig3_mechanism.py` | Main-text Figure 3: what governs the chain benefit (plot-only; reads stored results, no computation). |
| `03_fig5_regime.py` | Main-text Figure 5: the regime in which label-dependency models help (logistic regression). |
| `04_supp_learning_curves.py` | Supplementary figures: learning curves at both sites (hard, probability and, when available, stacking) and label efficiency for all three drugs at both targets. |
